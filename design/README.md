# Design integrity

AI Eponym Atlas does not ship generated UI mockups as product evidence.

Interactive graphs, timelines, formulas, labels, counts, and historical
likenesses must be rendered from the typed catalog or audited media records.
Generated imagery is allowed only when it is clearly decorative,
non-informational, inaccessible to pointer interaction, and documented in
[`docs/GENERATED_ASSETS.md`](../docs/GENERATED_ASSETS.md).

Design explorations that invent people, data, relationships, publications, or
interface text are rejected rather than archived in the repository. This keeps
the visual layer subject to the same evidence standard as the written atlas.
